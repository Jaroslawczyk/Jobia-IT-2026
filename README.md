# Атлас IT — «выбор класса»

Одностраничное приложение-справочник по IT-направлениям и технологиям
(рынок Польши / Варшавы / Европы / мира, зарплаты, спрос, риск замены ИИ).

Раньше всё лежало в одном файле `Jobia.html`. Теперь код разнесён по файлам:
разметка, стили по правилам **SMACSS**, скрипты — по логическим модулям.

## Как запустить

Просто открыть `index.html` в браузере (двойной клик). Сборка не нужна:
скрипты обычные, стили подключаются одним файлом `css/main.css`.

## Порядок подключения скриптов

Важен и задан в `index.html`:

1. `js/data/*` — сначала данные и переводы
2. `js/core/state.js` → `data-assembly.js` → `helpers.js` → `i18n.js` → `metrics.js`
3. `js/render/*` — функции отрисовки
4. `js/main.js` — навешивает события и запускает первый рендер

Все файлы делят общую глобальную область видимости (как в исходном
`Jobia.html`), поэтому каждое имя объявляется ровно один раз.

## Поток данных (кратко)

```
пользователь кликает → меняется поле state.* → вызывается render*() →
render*() читает данные + state, собирает HTML-строку → пишет в innerHTML
```

## Языки

16 языков: ru, en, pl, uk, be, de, fr, pt, it, cs, zh, hi, ar (RTL), am, ti, om.

- **Ленивая загрузка**: файл языка (`js/i18n/<code>.js`) подгружается
  динамическим `<script>` только при выборе языка. Открытие страницы
  не тянет все переводы. Работает и при открытии `index.html` напрямую.
- **Цепочка фолбэков** для каждого поля: текущий язык → английский → русская основа.
- **Полнота** (`ready` в пакете):
  `full` — переведено всё, включая глубокие разделы (**ru, en**);
  `cards` — интерфейс + лицевая часть карточек, глубокое — фолбэк на en (**pl**);
  `ui` — переведён интерфейс, всё содержимое карточек берётся из английского
  (uk, be, de, fr, pt, it, cs, zh, hi, ar, am, ti, om — на этом этапе).
  На непереведённых вкладках показывается плашка «раздел на английском».
- Английский разбит на 3 файла по объёму: `js/i18n/en.js` (разработка),
  `en-2.js` (данные/инфра/безопасность/качество), `en-3.js` (продукт/enterprise
  + `alt` + флаг `ready:"full"`). Грузятся сразу — en это универсальный фолбэк.
- **RTL**: для арабского на `<html>` ставится `dir="rtl"`; правки в
  `css/state/_rtl.css`. Шрифтовые фолбэки для арабицы, деванагари,
  эфиопского письма и CJK — в `css/base/_page.css`.

### Как дописать перевод языка

Открыть `js/i18n/<code>.js`, поднять `ready` до `"cards"` или `"full"`
и добавить ключи: `roles` (по id направления: name, tag, about, path,
ai, pros, cons, passive, ult, stack, extra, tracks, fw, tools, day),
`alt`, `facts`, `techW`, `techA`, длинные `ui.fn_*`, `ui.lead`,
`ui.sources`. Незаполненные поля продолжают падать на английский.
- **Выбор валюты** (PLN · EUR · USD · UAH · BYN · RUB). Числовые зарплаты
  хранятся в PLN и пересчитываются по курсам из `js/data/currency.js`
  (зашиты вручную, дата — в поле `updated`).
- **Фильтры (направления)**: группа, технология, поиск, риск ИИ,
  порог входа, время изучения «с нуля». Сортировка — по спросу, зарплате,
  числу вакансий, лёгкости входа, алфавиту.
- **Фильтры (технологии)**: тип, поиск, группа направлений (куда ведёт),
  сортировка (алфавит / число направлений / senior-зарплата).
- **Число вакансий**: на карточке направления — плашки «PL ≈ N» и
  «Варшава ≈ N»; в режиме технологий у каждой ссылки «Куда ведёт» —
  вилка jun/mid/sen и вакансии PL + Варшава.
- **Время изучения** — авторская оценка (`js/data/learning.js` +
  `js/core/metrics.js`): по каждому пункту стека и суммарно на карточке,
  отдельно «с нуля» и «со сменой стека».
- **Вкладка «Один день»** — как выглядит работа изнутри, от первого лица
  (`js/data/day-in-life.js`).
